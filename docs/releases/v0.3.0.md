# AgentCtl 0.3.0

AgentCtl 0.3.0 brings a more responsive conversation UI, stronger session delivery and recovery, and expanded workspace tools. This release includes the changes on `dev` since 0.2.0.

## Conversations and sessions

- Smoother streamed responses and thoughts, with less repeated rendering and background highlighting for long code replies.
- Faster navigation after hovering or focusing a session, with paginated history and a complete turn timeline.
- Visible message delivery states, recoverable failed sends, and queues scoped to each session.
- More reliable event-stream reconnection, provider recovery, and session shutdown.
- Compact approval requests in the composer, prompt history navigation, and double-Escape cancellation.
- Provider handoff, managed skills, and controls that follow the selected provider's capabilities.

## Workspaces and review

- Rewind and undo for conversation turns and file changes, with an in-chat recovery banner.
- Git review actions, pull request tracking, and an apply-session workflow.
- Expandable file diffs, quoted hunks, reference-only mentions, and virtualized review views.
- Split terminals, terminal tabs, and automatic reconnection.
- Folder drag and drop, improved quick launch, and configurable worktree defaults.
- Safer Git snapshots, worktree ownership checks, and recovery of missing workspaces.

## Interface and providers

- A consistent design system, more responsive layouts, and improved keyboard and accessibility behavior.
- Settings and authentication screens load when opened, reducing initial web JavaScript.
- Provider CLI detection, installation/download progress, authentication lifecycle fixes, and clearer persistent errors.
- Desktop completion notifications, notification preferences, and dynamic tray status.
- Updated dependencies and ACP SDK integration, with protocol-neutral session events and expanded conformance coverage.

## Performance validation

Opt-in local journey measurements, synthetic browser fixtures, and CI safeguards now cover startup code size, stream subscriber renders, prefetch reuse, and emitted Markdown workers in web and desktop builds. Timing reports remain comparison data rather than fixed latency promises. See [performance measurements](https://github.com/YoussefRnd/agentctl/blob/v0.3.0/docs/performance.md) for the scope and results.

## Upgrading

The Linux AppImage is attached to this release. Workspace package versions are aligned at 0.3.0.

Database storage and API contracts have changed since 0.2.0. Existing databases migrate on startup. Before upgrading, close AgentCtl and back up your data directory (by default `~/.agentctl`; use the location you configured if different). Keep that backup if you need to return to 0.2.0 after migration. Integrations using the standalone server API should be checked against the current contracts.
